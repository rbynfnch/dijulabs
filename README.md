# DIJULABS

Static Astro site. `npm install && npm run dev`; deploys to Netlify (`netlify.toml`).

## Add an app
1. Add an entry to `src/data/apps.ts` (name, slug, tagline, description, status, url, installable, screenshots).
2. Drop 2–4 screenshots in `public/apps/<slug>/` (390×844 ratio), plus optional `icon.png` (512×512) and a share image `public/og/<slug>.png` (1200×630).

That's it: the home card, `/apps/<slug>` page, sitemap and metadata are generated.

## Before launch
- Set the real domain in `src/data/site.ts` (`url`) and the real support link (`supportUrl`).
- Replace placeholder screenshots/icons/OG images (generated by `scripts/make-assets.py`).
- Put each app's real Netlify URL in `url`.

## Install button
`InstallButton` has two modes. On this site (`handoff`) it sends visitors to the app (`?install=1`), because a browser only offers PWA install on the app's own origin. Use `<InstallButton mode="native">` (or copy its script) inside an app to run the real `beforeinstallprompt` / `appinstalled` flow. iOS shows "Share → Add to Home Screen" instructions. It never reports success before `appinstalled` fires.
